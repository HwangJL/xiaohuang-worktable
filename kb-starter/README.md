# kb-starter — 知识库起步模板

驾驶舱的「项目知识」页面按 `kb/SCHEMA.md` 的规则检索与写入。这里是把这套结构复制到你工作区的最小集合。

## 用法

```powershell
Copy-Item .\kb-starter .\<你的工作区>\kb -Recurse
```

复制后工作区里是：

```
kb/
├─ SCHEMA.md      规则：三层结构（raw → wiki → schema）、三个操作（ingest / query / lint）
├─ templates/     七类页面模板（实体 / 概念 / 决策 / 摘要 / 对比 / 故障 / 待确认）
└─ wiki/          正文目录（起步时为空；插件按 SCHEMA 新建页面，不覆盖正式页）
```

## 规则要点（细节看 `SCHEMA.md`）

- `raw/` 放原始资料（只读）；`wiki/` 放编译出的结论（带状态、带来源、可被后续工作引用）。
- 页面 ID 单调递增：`E` 实体、`C` 概念、`D` 决策、`S` 摘要、`X` 对比、`I` 故障、`Q` 待确认。
- `status` 三档：`正式` 才能作为设计依据，`待确认` 只能参考，`历史` 只用于追溯。
- 未确认的内容不得覆盖 `正式` 页；矛盾两版并存并标冲突，由人裁决。
